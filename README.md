# HirePilot

Your AI Copilot for the Next Career Move.

HirePilot is an AI-powered job search platform designed to help users discover relevant job opportunities, manage job applications, and prepare professional application emails.

## Features

- Search jobs by designation and location
- Filter job opportunities
- Save interesting jobs
- Explore company contact information
- Generate professional HR application email drafts

## Tech Stack

- React
- Vite
- Node.js
- Express.js
- REST API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Rahul-shastri67/HirePilot.ai.git
cd HirePilot-Ai
```

Install dependencies and start the application using the instructions in the project.
